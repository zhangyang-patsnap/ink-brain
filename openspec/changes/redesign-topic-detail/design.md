## Context

专题是后台编排的文章、项目与工具集合，而不是单篇文章。现有 topicCatalog 已过滤不可用内容；详情不渲染历史 body，本次保持该边界。

## Goals / Non-Goals

**Goals:** 紧凑介绍与完整有序列表；首屏可见内容入口；无脚本也可浏览；主题和手机适配。

**Non-Goals:** 不改首页/文章/项目详情，不加侧栏、自定义分类、学习进度或后台字段，不自动发布。

## Decisions

- 采用专题导览而非文章阅读器：上方软纸色展签，下方有序横向条目。展签侧边使用强调色细边作为视觉标记，不为单项内容制造空侧栏。
- 沿用站点色彩令牌：纸色 #f1eee5、深纸色 #e6e0d4、墨色 #181714、辅助墨色 #5e5951、朱红 #bd3f29；工作台及暗色自动替换，不新建主题。
- 标题用现有 display 字体 32–40px，条目标题 22px，简介 sans 14–15px，序号 mono。最大宽度 1160px，手机单列且完整换行。
- 将引用解析抽为 topicSequence，首页 preview 仍返回原结构；详情使用全量有效 items 和同源统计。保持编排顺序，不按类型重新分组。
- 每行一个原生链接，含编号、类型、标题、简介、对应操作（阅读文章/查看项目/使用工具）。链接可聚焦，不用重复嵌套链接或 JS 点击容器。
- 用户追加类型筛选：在内容标题下使用全部/文章/项目/工具原生按钮与 aria-pressed，默认全部。零数量类型可选并显示空结果。只切换现有条目的 hidden，不重排或重编号。不增加分类模型或网络请求。无 JS 隐藏筛选栏，仍可查看全部内容。筛选数量使用 status 向辅助技术播报。

## Risks / Trade-offs

- 长标题/简介 → 不裁剪文字、不限制固定高度，并验证 320px。
- 专题只有一项/没有有效引用 → 真实计数，完整单条目或清楚空态，不出现无效开始按钮。
- 新 CSS 与旧样式冲突 → 全部使用 topic-guide 前缀，仅详情组件引入。
- 发布快照不同于源码 → 分别构建验证，隔离预览更新不触碰 active.json 或草稿。
