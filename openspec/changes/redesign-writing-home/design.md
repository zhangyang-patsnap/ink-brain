## Context

Astro 静态文章首页当前复用 PageIntro/ArticleRow。用户选择 B 编辑选读的布局，要求文章页与专题区分，不需要分类。现有 schema 无选读字段。

## Goals / Non-Goals

**Goals:** 紧凑且有编辑感的页头、自动最新选读、双列其余文章、全部文章可搜索、保持两套主题与手机阅读。

**Non-Goals:** 新分类体系、人工推荐管理、专题/项目/详情页改版、自动发布草稿。

## Decisions

- 最新已发布文章自动作为选读，同日用 id 排序保证稳定；不硬编码文章 id，不改数据。
- 全部内容服务端生成，搜索是渐进增强。无 JS 时正常阅读，搜索控件仅初始化后显示。
- 每条网格卡片包含安全转义的标题与摘要搜索字段。默认隐藏最新文章的普通卡片；搜索时隐藏选读，过滤全部普通卡片，清除恢复初始布局。
- 查询按空白分词、大小写和 Unicode 宽度归一化，在标题摘要中匹配所有词；不发起 API 请求，不使用用户输入拼接 HTML。
- 单独 WritingHome 组件与 writing-home 样式，不修改公用 ArticleRow，以免影响标签页。沿用纸上 #f1eee5/#f7f4ec/#181714/#bd3f29 与工作台 #f3f5f5/#fff/#202b30/#23645c 令牌。
- 视觉主体是一条横向选读版面：左侧标题日期，右侧摘要入口，细竖线分层；下方双列文章。页头 36px，文章标题 24px，正文摘要 14px，手机单列，不增加图片依赖。

## Risks / Trade-offs

- 最新文章可能仍叫“测试” → 尊重用户内容，不替换标题；明确选读取最新。
- 空列表/仅一篇可能出现多余分隔线 → 静态显式处理、用组件渲染边界测试。
- 发布快照与源码数据不同 → 分别构建源码和隔离发布预览，不擅自切换 active release。
