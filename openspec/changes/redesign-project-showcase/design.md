## Context

项目数据已有名称、type、status、demo、tagline、summary、stack、capabilities、documentation、项目地址和多源码/多文档地址。当前发布数据只有一个示例项目，无真实外部入口。

## Goals / Non-Goals

**Goals:** 落地 C 作品展台首页/详情，真实数据自适应，README 完整可读，目录与链接可用，主题/手机/键盘支持。

**Non-Goals:** 不加分类模型、封面或排序器，不引入虚构许可证和项目内容，不发布草稿，不改其他模块。代码协议与主要语言仅作为本轮明确需要的可选资料字段。

## Decisions

### 等宽双展台（本轮最终布局，替代窄侧栏）

- 用户明确完整参考图两侧要同时呈现且等宽；桌面 grid-template-columns 为 repeat(2, minmax(0, 1fr))，不是 224/270px 导航侧栏。
- 左栏复用 ProjectShowcase：完整两行主标题、说明、右侧竖线小字、横向真实类型筛选；首项整块红色跨两列，其余双列普通卡，带类别/标题/介绍/摘要/状态技术栈及右上角小字。奇数空位用模板引语而非虚构项目补齐。
- 左栏在 inline 模式只派发项目选择，由 workspace 统一处理筛选和 URL；保留独立使用组件的原筛选。右侧复用现有详情。
- 桌面两栏等宽且顶部对齐，移动端上下排列，首次保留完整卡片展台，选择后可折叠并聚焦详情。不复制两套全站导航/页脚。

### 原图复刻决策（替代此前近似的 C 校正）

- 以用户提供的 codex-clipboard-17d3c865-e0fd-4483-91cb-a1435816c058.png 为布局依据；保留左侧选择器，右侧是一张完整的纸面项目详情，不再铺满空白画布。
- 浅色标题带内按类别、衬线标题、介绍及就近状态、三种资源按钮、入口说明排列；右上独立竖线小字使用真实项目类别，不重复状态。四栏元信息以竖线隔开：类型、技术栈、代码协议、主要语言。
- 本轮允许增加可选 license、languages 字段及后台编辑入口，以让四栏信息可维护；不推断许可证/编程语言。无值显示未提供，未配置资源保留明确禁用的按钮槽位，禁止伪造地址。
- 正文按项目介绍、核心能力、README 内实际标题排列；已有 Markdown 标题直接成为文档目录，不额外套重复 README 标题。缺省文档仍明确提示。右侧窄目录与介绍顶部对齐，当前章节用红色竖线指示。
- 保留本站导航、页脚、主题，不在嵌入详情里制造第二份站点导航或页脚；不修改真实项目内容，不触发正式发布。

### 最新交互决策：首页直接阅读（替代下方早期卡片布局决策）

- /projects/ 使用左侧约 270px 项目列表、右侧自适应详情；首页标题收在左侧，右侧沿用 C 的标题、信息带、资源入口、介绍/README 和目录，首项默认展示。
- 新增 ProjectWorkspace 复用 ProjectDetail 的 embedded 模式；仍保留独立详情路由。嵌入时调整 heading 层级和边距，不修改数据模型。
- 首页静态渲染首项正文，其余详情存于 inert template；切换时仅挂载一个正文，防止重复目录 ID 和隐藏容器 Mermaid 尺寸问题。
- URL ?project=slug 保存选择，刷新/前进/后退可恢复。原生链接在无 JS 时仍进入独立详情，增强后直接切换，Ctrl/Command 点击可打开带选择参数的首页。
- 筛选使用真实类型；当前项目被筛掉时选择首个可见项目。手机列表使用原生 details 折叠，选择后正文获得焦点；桌面侧栏可独立滚动。
- Mermaid 保持原渲染器，增加在途去重以避免首页初始化和项目选择重复渲染同一代码块。
- 本次只更新隔离预览，不触发正式发布或覆盖后台数据。

- 新 ProjectShowcase / ProjectDetail 组件及 project-showcase.css，保留现有路由和数据源。全局样式不改动。
- 按原始 C 图校正：首页两行主标题，真实类型筛选，第一张始终跨两列、整块强调色（名称、介绍和元信息统一在色块内），其余双列，手机单列。不再左右拼接，也不随奇偶改变首卡结构。筛选后首个可见项目采用首卡形式，维持原有顺序；不编造分类或项目。
- C 的视觉用字与色块体现系统身份，不增加截图负担。沿用纸色 #f1eee5、软纸 #f7f4ec、墨色 #181714、辅助墨 #5e5951、线色 #c9c1b4、强调色 #bd3f29；工作台/暗色继续使用现有令牌。标题 display 34–42px，卡片 26–34px，README sans 16px/1.85。
- 详情标题/一句话介绍/操作区集中；技术栈和状态横向呈现。主内容约 78% + 右侧目录约 22%，总宽 1240px，手机折叠目录在正文前。README 主导，不套用旧 article-prose 的大间距。
- 使用既有 renderMarkdown 安全清洗后，在服务端为文档标题生成稳定唯一 ID，目录静态渲染，因此无 JS 也能跳转。README 标题降级以维护页面 heading 层级。表格、代码局部横向滚动；图像响应式，Mermaid 复用 BaseLayout 的全局渲染和放大。
- 链接仅接受 http/https，去空/重复，兼容旧单地址，无配置则不渲染。多个地址独立呈现且编号，不替用户推断目标用途。不对外部系统发请求或宣称已部署。
- 介绍、核心能力读取已有字段；README 为 documentation，不添加示例安装命令。空 README 显示未提供说明。

## Risks / Trade-offs

- 多/少项目的留白 → 首卡加双列、单/空数据浏览器验证，不补空卡片。

## C 模板校正

- 详情去掉额外左侧色条及卡片背景，状态靠近一句话介绍；项目信息使用带竖分隔的类型/技术栈两栏，项目介绍回到正文。未配置许可证/链接仍不虚构。
- 分类只使用现有 type，原生按钮、aria-pressed 和结果播报；无 JavaScript 时隐藏筛选按钮并完整展示项目。
- 长标题及 Markdown → 完整换行，独立局部滚动，HTML 清洗和锚点生成测试。
- 页面与旧 CSS 冲突 → project-showcase / project-sheet 前缀隔离。
- 发布数据不同 → 本地源码测试及隔离发布快照预览，不修改 active.json。
