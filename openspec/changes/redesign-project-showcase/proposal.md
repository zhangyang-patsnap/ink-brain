## Why

项目模块应展示作者研发的后端系统，现有大标题与横向目录不利于浏览。用户已选择 C「作品展台」，需要成对落地项目首页和详情。

## What Changes

- 首页最终改为左侧项目选择、右侧完整详情，保留 C 的排版与资源入口，无需进入二级页面。
- 详情顶部集中展示介绍及真实项目/多源码/多文档入口，下方以 README 为主体，右侧提供自动目录。
- 保持现有两套主题、深浅色、移动端和静态访问能力。
- 不引入效果图示例项目、虚构许可证或封面；为模板四栏资料补充可选代码协议、主要语言后台字段。

## Capabilities

### New Capabilities
- `project-showcase`: 卡片作品集与可阅读、可导航的项目详情。

### Modified Capabilities
无。

## Impact

涉及 projects 路由、新项目组件和隔离样式/文档辅助函数，以及项目 schema/后台的两个可选资料字段。不改 URL 或正式发布状态。复用现有 Markdown 清洗和 Mermaid 渲染。
